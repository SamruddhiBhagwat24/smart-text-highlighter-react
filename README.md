# ✨ Smart Text Highlighter

**Smart highlights. Instant insights.**

Smart Text Highlighter is a frontend-based web application that helps users quickly understand text by extracting and highlighting the most important information using AI.

---

## 📌 Project Overview

The user enters any paragraph or text, and the application sends it to the Gemini AI API. The AI analyzes the content and returns only the essential insights, which are displayed in a simple underlined format for easy readability.

---

## 🚀 Features

- AI-powered extraction of essential insights from text  
- Clean underline-style highlighting for extracted points  
- Organized display of insights in a card-based layout  
- Real-time word and character counter  
- One-click copy of extracted insights  
- Simple and user-friendly interface  

---

## ⚙️ Project Structure & Working

Smart Text Highlighter is built using React and Vite and runs completely on the frontend.

**Working Flow:**
1. User enters text in the input box.
2. On clicking the **Highlight** button, the text is sent to the Gemini AI API.
3. The AI analyzes the content and extracts key information.
4. The extracted insights are displayed with underline highlighting.
